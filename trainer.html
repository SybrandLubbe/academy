00Java Primer for AEM

1. In an AEM project, what command builds and deploys your code, and from which folder do you run it?

mvn clean install -PautoInstallSinglePackage, run from /aem-academy (the project root).

2. A build succeeds but curl returns a 404 for your new servlet. What should you check first, and what's almost always the real cause?

Check /system/console/components — it's almost always a registration property typo (like a wrong sling.servlet.paths), not a missing deploy.

3. Why split GreetingService into an interface plus a separate GreetingServiceImpl instead of one class?

Encapsulation — consumers depend on the contract, not the implementation, so the implementation can be swapped without touching anything that uses it.

4. What annotation does StudentModel use to read a property like "name" straight off the resource, and what happens if a required field can't be filled?

@ValueMapValue. If a required field has nothing to inject, the whole model fails to instantiate and adaptTo() returns null instead of a half-populated object.

5. ValidationServlet throws InvalidUserException, a checked exception. What HTTP status does it return when validation fails, and why use a checked exception here?

400. A checked exception forces callers to explicitly handle the failure case, modeling "this can and will happen for bad input" rather than treating it as an unexpected bug.

6. What two specific rules does validateUser() enforce in the exercise?

Username must not be blank, and "admin" (case-insensitive) is a reserved username.

7. ChildPagesModel reads its children with a stream pipeline. What collection type does resource.getChildren() return, and why is StreamSupport.stream(...spliterator()...) needed?

It returns an Iterable<Resource>, not a Collection, so StreamSupport.stream(resource.getChildren().spliterator(), false) is needed to turn it into a Stream.

8. What annotation makes a Sling Model exportable via the .model.json selector?

@Exporter(name = "jackson", extensions = "json").

9. HelloWorldServlet extends SlingSafeMethodsServlet. What does "safe" mean here, and which HTTP method does the example register for?

"Safe" methods don't change server state (GET, HEAD, OPTIONS); the example registers for GET via sling.servlet.methods=GET.

10. If a junior's checkout isn't literally named "aem-academy," what should they do with every file path given in this curriculum?

Mentally substitute their own project's root folder name and package (biz.netcentric.academy) everywhere /aem-academy appears.

01Architecture Overview

1. AEM is described as three open-source projects stacked together, plus Adobe's apps on top. Name the three.

Apache Jackrabbit Oak (the repository), Apache Sling (the resource framework), and Apache Felix/OSGi (the runtime).

2. In a typical MVC framework you define routes. How does Sling's approach to "routing" differ?

There's no separate route table — the content tree itself is the routing table; Sling maps the URL path directly onto a repository path.

3. What does OSGi let you do with bundles that a typical monolithic Java app can't easily do?

Load, wire, and hot-swap modular JARs (bundles) independently, without restarting the whole server.

4. What's the difference between an author and a publish instance, in terms of what each is for?

Author is where content is created/edited (never exposed to end users); publish serves the live public-facing site with a replicated copy of approved content.

5. What triggers replication, and what does it actually move?

Activating a page triggers it; it pushes content (and sometimes code) from author to publish.

6. What two jobs does the dispatcher do?

Caches rendered pages as static files, and acts as a security gatekeeper blocking requests that don't match an allow-list of safe URL patterns.

7. Why does a service registered or configured on author not automatically exist on publish?

Author and publish are separate JVMs with separate copies of the repository — nothing is shared automatically.

8. What's the rule about /libs, and what should you do instead of editing it directly?

Never edit anything under /libs (it's overwritten on every upgrade); instead, overlay it by recreating the path under /apps.

9. Which module covers exactly how that /apps overlay resolution works?

Module 4, Sling Framework Fundamentals.

10. What's the most common category of "it works locally but not in production" bug this module warns about?

Dispatcher rules — issues that don't show up in a single local author-only setup.

02JCR & the Content Repository

1. A page in AEM is actually two nodes stacked together. Name them and their primary types.

The cq:Page node (e.g. /content/my-site/en/about) and its jcr:content child node (cq:PageContent).

2. Where does a page's title actually live — on the cq:Page node or somewhere else?

On the jcr:content child node (as jcr:title), not on the cq:Page node itself.

3. What does the jcr: namespace prefix indicate, versus cq: versus sling:?

jcr: = core JCR spec concepts; cq: = AEM-specific concepts (from the old Communiqué product); sling: = Sling-specific properties like sling:resourceType.

4. Which top-level repository path should you NEVER edit directly, and what should you do instead?

/libs — never edit it directly (overwritten on upgrade); overlay it under /apps instead.

5. What's the simple mental-model question to ask when you're not sure whether something belongs under /content or /apps?

"Is this content an author typed in, or code a developer wrote?" Content → /content, code → /apps.

6. What does the mix:versionable mixin type enable on a node?

Participation in JCR versioning — it's what powers features like page version history.

7. What's CRXDE Lite good for, and what is it explicitly NOT meant for?

Good for poking around and quick debugging; not where you do real development.

8. What's the alternative to walking the tree by hand when you need to find nodes by criteria, like "all pages using template X"?

Query Builder / JCR-SQL2.

9. Name four common JCR property types mentioned in this module.

String, boolean, date, and binary (long and reference types are also mentioned).

10. Why does the page/jcr:content split "trip up almost every new developer at least once"?

Because querying the page node itself for title/properties returns nothing — that data lives under the jcr:content child node instead.

03Sling Framework Fundamentals

1. In your own words: why does Sling not need a separate routing table/config file like a Spring or Express app does?

Because the URL path maps directly to a node in the JCR repository, and that node carries a sling:resourceType property that points to the component that renders it. The content tree is the routing table — no separate config needed.

2. A URL is /content/shop/products.sale.json/category/shoes — identify the path, selector, extension, and suffix.

Path = /content/shop/products, selector = sale, extension = json, suffix = /category/shoes.

3. What is a Resource, and what are the two things it gives you access to?

A Resource is Sling's wrapper around a JCR node. It gives you: (1) the node's path, and (2) a ValueMap — a typed map of every property on that node.

4. An author adds a Teaser component to a page. What property on that component's content node tells Sling which script to render it with?

sling:resourceType — its value is a path to the component folder under /apps (or /libs) that contains the render script.

5. Sling looks for a render script in /apps first, then /libs. Why does this order matter, and what pattern does it enable?

Because /apps is always searched first, you can place a file at the same path under /apps and it silently takes priority over the Adobe default in /libs. This is called an overlay, and it's the correct way to customise out-of-the-box AEM components.

6. A junior developer edits a file under /libs to fix a bug. It works. Three weeks later the fix is gone. What happened, and what should they have done instead?

An AEM service pack or upgrade overwrote /libs completely. They should have created an overlay — a copy of the file at the same path under /apps — so their change survives upgrades.

7. What does sling:resourceSuperType let you do, in plain English? Give a practical example.

It lets a component inherit render scripts from another component without copy-pasting them. Example: a custom Teaser that sets sling:resourceSuperType to the Core Teaser inherits all of its scripts and only needs to add or override the parts that differ.

8. You have a News Article component and you want to render it differently for mobile devices. You don't want to change the content. How could you use selectors to achieve this?

Add a selector-specific script: e.g. article.mobile.html alongside article.html. Mobile requests use the .mobile. selector and Sling routes them to the mobile-specific script, while desktop requests continue to use the default.

9. What is the difference between a selector and an extension, and how does each one participate in Sling's script resolution?

A selector is a dot-separated word between the path and the extension (e.g. print in page.print.html); the extension is the final segment (e.g. html, json). Both are used to find the exact script — Sling looks for a file named resourceTypeName.selector.extension.

10. A content node has sling:resourceType = 'academy/components/hero'. Sling looks for hero.html — where does it look, and in what order?

First /apps/academy/components/hero/hero.html, then /apps/academy/components/hero/html.jsp (older JSP form), and only if neither exists does it fall back to the same paths under /libs.

04OSGi: Bundles, Services & Components

1. In plain English: what is an OSGi bundle, and how is it different from a regular Java JAR?

A bundle is a JAR with extra metadata in its MANIFEST.MF that declares what Java packages it exports (shares with others) and imports (needs from others). OSGi uses this to wire bundles together and load them in the right order. A regular JAR has no such contract.

2. A bundle is stuck in the RESOLVED state instead of ACTIVE. What does this tell you, and where in the Felix console do you look to find out why?

RESOLVED means all package-level dependencies are met, but a component inside the bundle has an unsatisfied @Reference. Go to /system/console/components, find your component, and read the 'unsatisfied references' list to see which service type has no active provider.

3. What is the difference between an OSGi component and an OSGi service? Can you have a component that doesn't publish a service?

A component is a Java class annotated with @Component — a managed unit of code. A service is a capability it publishes to the registry via the service attribute. Yes, a component can exist without publishing any service (e.g. a standalone event listener with immediate = true).

4. What does @Component(service = GreetingService.class) actually do — what is written to the registry, and under what key?

It registers the implementing class in the OSGi service registry under the GreetingService interface as the key. Any component that asks for GreetingService via @Reference will get this implementation injected.

5. Why do we use @Reference instead of just writing 'new GreetingServiceImpl()' to get a dependency?

@Reference lets OSGi inject whatever is currently registered as that service type, without hardcoding a dependency on the concrete class. This enables swapping implementations, testing with fakes, and letting OSGi manage the lifecycle — none of which work if you use new.

6. You deploy a new GreetingServiceImpl but GreetingServlet still uses the old behaviour. You check /system/console/components and see GreetingServlet is 'unsatisfied'. What does this mean?

GreetingServlet has a @Reference that OSGi can't satisfy — perhaps the new GreetingServiceImpl didn't deploy successfully (check the bundle state), or it registered under a different interface name.

7. What is @Activate used for? Give a real example of something you'd do inside it.

@Activate marks a method to be called when the component starts (and when config changes if you also add @Modified). Real example: reading configuration values and storing them as fields, opening a connection pool, or scheduling a background timer.

8. What does @Deactivate do, and when is it called?

@Deactivate marks a method called when the component is stopped — on bundle uninstall or AEM shutdown. Use it to clean up resources: close database connections, cancel scheduled tasks, release thread pools.

9. You edit a configuration value in /system/console/configMgr and it works. Three days later, a colleague deploys and your change is gone. Why?

The Felix console stores config in the JCR repository of that one instance. A deployment replaces it with whatever is in the project's ui.config .cfg.json files. Any hand-edited value that isn't also committed to source control will be silently overwritten on deploy.

10. Name the two Felix console URLs every AEM developer must know, and describe in one sentence what each one shows you.

/system/console/bundles — shows every bundle and its lifecycle state, plus unsatisfied imports for anything not ACTIVE. /system/console/components — shows every OSGi component, its state, and which @Reference fields are unsatisfied.

05OSGi Services & Configuration

1. What does 'MANDATORY' reference cardinality mean, and what happens to the consuming component if no matching service is registered?

MANDATORY (the default) means the component cannot start without exactly one matching service. If none is registered, the component stays in the 'satisfied' state but never activates — it appears in /system/console/components with an 'unsatisfied references' list.

2. Why must OPTIONAL and MULTIPLE references be declared volatile? Explain in plain English, not just 'it's required'.

Because OSGi can inject or remove these services while the component is already running (as bundles start and stop). The volatile keyword prevents the JVM from caching the field's value in a CPU register — without it, a thread might read a stale null or a reference to a service that was unregistered seconds ago.

3. You write an event listener with @Component but it never seems to fire, even though the component shows as 'satisfied' in /system/console/components. What is the most likely cause?

Missing immediate = true. Without it, OSGi activates the component lazily — only when something else references it. Since nothing ever calls @Reference on a listener, it never activates and never starts listening.

4. What does immediate = true do, and which types of components almost always need it?

It forces the component to activate the moment its bundle becomes ACTIVE, without waiting for anyone to reference it. Components that need it: ResourceChangeListeners, Sling Schedulers, JobConsumers, EventHandlers — anything that runs proactively rather than being called.

5. Give two concrete reasons why splitting a service into an interface and a separate implementation class matters in a real project.

(1) Swappability: any consumer holds only the interface type, so the implementation can be replaced (e.g. with a mock in tests, or a different provider in production) without changing any consumer code. (2) Multiple implementations: you can register two implementations of the same interface and use service ranking or target filters to control which one each consumer gets.

6. What is the naming convention for a .cfg.json file, and where in the project does it live?

The file is named after the component's OSGi PID — its fully-qualified class name — e.g. biz.netcentric.academy.GreetingServiceImpl.cfg.json. It lives under ui.config/src/main/content/jcr_root/apps/academy/osgiconfig/config/ (or a run-mode-scoped subfolder).

7. A colleague edits a log level in /system/console/configMgr. It works. You deploy the next morning and the log level is back to the old value. Explain exactly what happened.

The deployment installed the content package from ui.config, which contained the old .cfg.json value. The hand-edited console change was stored only in the JCR of that instance and was overwritten by the deploy. Fix: commit the desired value to the .cfg.json file in source control.

8. An AEM instance has run modes 'author' and 'dev' active. You have config folders: config/, config.author/, config.author.dev/. Which one applies, and why?

config.author.dev/ applies — AEM picks the most specific folder that matches all active run modes. Since the instance is both 'author' and 'dev', the two-label folder wins over the single-label folders.

9. You need the same service to point at a mock API on dev but a real API in production. How do you implement this without changing any code and without touching the Felix console manually?

Create two .cfg.json files with the same PID: one in config.author.dev/ (or config.dev/) pointing at the mock URL, and one in config/ (or config.publish/) pointing at the real URL. Deploy both; AEM applies the right one per environment automatically.

10. What is the OSGi PID of a service, and how do you find it if you're unsure what to name your .cfg.json file?

The PID is the fully-qualified class name of the component (e.g. biz.netcentric.academy.GreetingServiceImpl). To find it: deploy the service, open /system/console/configMgr, find the entry by its @ObjectClassDefinition name, and read the PID shown in brackets.

06Sling Models

1. In your own words: what problem does a Sling Model solve? What would the alternative look like without one?

A Sling Model moves repository-reading code out of the render template into a clean, testable Java class. Without it, templates would contain property lookups, type casts, null checks, and business logic — mixing data access with presentation, making both harder to test and maintain.

2. What does 'adaptation' mean? Rewrite 'resource.adaptTo(TeaserModel.class)' in plain English as if explaining to a non-developer.

Adaptation means 'convert this object into a different, related type.' In plain English: 'Sling, please take this content node and give me a TeaserModel Java object filled with its data.'

3. What does @ValueMapValue read, and where does the value come from in the repository?

It reads a property directly from the content node's ValueMap — the JCR property whose name matches the field name (or the name you specify in the annotation). For example, @ValueMapValue on a field named 'title' reads the 'title' property from the node.

4. What is the difference between @ChildResource and @ValueMapValue — when would you use each one?

@ValueMapValue reads a flat property (String, boolean, int, etc.) from the current node's ValueMap. @ChildResource resolves a named child node as a Resource object (or adapts it to another model). Use @ChildResource when complex data lives in a sub-node rather than as a flat property.

5. A required field on a model has no matching property on the content node. What does adaptTo() return, and does it throw an exception?

It returns null — no exception, just a silent null. This is a major pitfall: you get no error, and your template silently renders as blank.

6. What does defaultInjectionStrategy = DefaultInjectionStrategy.OPTIONAL do to a whole model class?

It makes every injected field optional by default — if a property is missing, the field stays null and adaptation still succeeds. Individual fields can still be marked @Required to override this. Use it for content fields that may legitimately be empty.

7. You call adaptTo() and get null. Walk through the steps you would take to debug this.

(1) Go to /system/console/slinglog and set DEBUG on org.apache.sling.models.impl. (2) Trigger the request again. (3) Read the log — it lists each field injection attempt and the first failure. Fix that field (wrong type, wrong property name, or a required service not available).

8. What is @PostConstruct for, and at what point in the lifecycle does it run relative to field injection?

@PostConstruct marks a method to run after all field injection is complete, but before the model is returned to the caller. Use it to derive computed values (truncate text, combine fields, run validations) that depend on the injected data being fully available.

9. What does the @Exporter annotation do, and what URL pattern does it respond to?

@Exporter(name='jackson', extensions='json') makes the model's public getters available as JSON at the resource path with the .model.json selector appended — e.g. /content/site/page/jcr:content/teaser.model.json.

10. You want to inject the ResourceResolver into a model. Which annotation do you use?

@SlingObject — it injects Sling framework objects including ResourceResolver, Resource, SlingHttpServletRequest, and SlingHttpServletResponse.

07Sling Models In Depth

1. Describe in your own words what adaptTo() does internally — what is the mechanism that makes it work?

adaptTo() looks up the OSGi service registry for a registered AdapterFactory that can convert the source type (e.g. Resource) to the target type (e.g. TeaserModel). The Sling Models AdapterFactory intercepts the call, reads the @Model annotation, runs injection on every annotated field, calls @PostConstruct, and returns the populated instance — or null if a required field failed.

2. You declare adaptables = SlingHttpServletRequest.class on a model. A colleague tries to inject it inside another model via @ChildResource. It always comes back null. Why?

Because the inner model adaptation is triggered from a Resource (no request exists at that point), but the model declares it can only be adapted from SlingHttpServletRequest. The AdapterFactory finds no matching adaptable and returns null. Fix: change adaptables to Resource.class if the model doesn't genuinely need request data.

3. What are two things you have access to with SlingHttpServletRequest that you don't get from a bare Resource? Give concrete examples.

(1) URL selectors — e.g. request.getRequestPathInfo().getSelectorString() returns 'print' for /page.print.html. (2) Query/form parameters — request.getParameter('q') for a search term. A Resource alone has neither of these.

4. Show the constructor injection version of a model that injects a title String and a price double. What is the advantage over field injection for these two fields specifically?

@Inject public ProductModel(@ValueMapValue String title, @ValueMapValue double price) { this.title = title; this.price = price; } — Both fields can be final, making the object immutable and fully valid the instant it's constructed with no @PostConstruct needed.

5. What does 'adapters = Teaser.class' in the @Model annotation do, and why does it matter for the module 8 composition pattern?

It registers the implementation class under the Teaser interface in the adapter registry — callers do resource.adaptTo(Teaser.class) and get TeaserImpl back. Module 8's composition pattern relies on adapting to Core Component interfaces (like com.adobe.cq.wcm.core.components.models.Teaser) which Core Components publish this way.

6. You deploy a new Sling Model but adaptTo() keeps returning null. You haven't changed the content node. Walk through three things you would check.

(1) Enable DEBUG logging on org.apache.sling.models.impl to find which field failed. (2) Check /system/console/bundles to ensure the bundle is ACTIVE (not just RESOLVED). (3) Verify the resourceType in the content node matches the resourceType declared on the @Model annotation exactly — case-sensitive.

7. Why is there no @Component annotation on a Sling Model, and how does OSGi know the model exists at all?

The Sling Models Maven plugin (bnd plugin integration) scans compiled classes for @Model annotations during the build and generates the OSGi AdapterFactory registration metadata automatically. No manual @Component registration is needed.

8. A model needs to call a geocoding API to convert a city name to coordinates. Should this happen in @PostConstruct, in an @OSGiService, or somewhere else entirely? Explain.

Neither @PostConstruct nor directly. The call should happen in an OSGi service (injected via @OSGiService), or better: in a scheduled Sling Job (module 18) that caches the result. Doing I/O in @PostConstruct blocks the render thread on every page load.

9. What is the difference between @OSGiService in a model and @Reference in an OSGi component? What do they share?

They perform the same lookup against the same OSGi service registry and inject the same type. The only difference is the annotation name — @Reference is used in @Component-managed classes, @OSGiService is used in Sling Models (which are not OSGi components). Both will return null (or prevent activation/adaptation) if no matching service is active.

10. Give a rule for deciding whether a configurable value should come through @OSGiService + @Designate, or through ConfigurationBuilder + @Self in the model.

If the value is the same for all sites on the instance and only changes between environments (dev/staging/prod), use OSGi config through a service. If the value should differ per site or per piece of content in the same instance, use Context-Aware Configuration via ConfigurationBuilder directly in the model.

08Extending Core Component Models

1. In plain English, what does @Via(type = ResourceSuperType.class) tell Sling Models to do?

Before injecting into this model, first adapt the same resource to whatever model the resourceSuperType registers, and hand you that already-built object.

2. What's the model-layer equivalent of this composition pattern at the render-script layer?

resourceType/resourceSuperType inheritance for render scripts — the same overlay/inheritance idea, applied at the model layer instead.

3. Why does reusing a Core Component's model usually beat reimplementing a component like Image or Teaser from scratch?

The Core Components ship years of refined accessibility markup, responsive image handling, edit-mode placeholders, and dialog UX that reimplementing from a blank HTL file throws away.

4. What's the difference between "composing by wrapping" and "composing by interface inheritance"?

Wrapping holds the core model in a private field and exposes your own getters (more control, can diverge from the parent); interface inheritance has your interface extend the core component's interface directly (more honest when there's no divergence).

5. Which approach should you default to, and when should you reach for the other?

Default to wrapping; reach for interface inheritance only when you're confident you'll never want to diverge from the parent's behavior.

6. What two test dependencies does core/pom.xml need before any unit test will run at all?

io.wcm.testing.aem-mock.junit5 and mockito-core (both scope test).

7. Where do test classes live relative to main source?

In a parallel src/test/java folder (instead of src/main/java), mirroring the same package structure.

8. In the AcademyTeaserModel example, what does @Self combined with @Via(type = ResourceSuperType.class) inject?

A fully populated instance of the Core Components' own Teaser model for the same resource.

9. What's the benefit of adding a new field like badgeLabel to a composed model, versus reimplementing title/link logic yourself?

You only need to add what's actually new — the inherited fields' fallback logic, link resolution, etc. are already handled by the wrapped core model.

10. Which later module covers unit testing properly, building on the test setup introduced here?

Module 14, Unit Testing.

09HTL Templating

1. What's the core security problem HTL was designed to eliminate that JSP had?

JSP made output escaping the developer's responsibility on every line; a single missed escape was an XSS bug waiting to happen. HTL removes scriptlets and arbitrary method calls so escaping is automatic.

2. What does data-sly-use do?

Instantiates a Sling Model (or legacy Use-API class) and binds it to a name you can reference in ${ } expressions.

3. Can a ${ } expression call a method with arguments? What does that constraint mean for where logic belongs?

No — expressions are deliberately limited to reading properties/indexing/operators. Any logic needing parameters belongs in the model, not the template.

4. What's the difference between data-sly-test and just hiding an element with CSS?

data-sly-test removes the element entirely from the output when the expression is falsy, rather than just visually hiding it.

5. What loop helpers does data-sly-list give you for free?

item.index, item.count, item.first, item.last (for the named iteration variable).

6. How does data-sly-repeat differ from data-sly-list?

data-sly-repeat keeps the wrapping element itself in the output once per item, while data-sly-list only repeats the children.

7. How does HTL decide whether to apply HTML-escaping, URI-escaping, or JS-string-escaping to an expression's output?

It infers it automatically from where the expression sits in the markup (context-aware escaping) — you don't choose it yourself.

8. What does context='unsafe' do, and why is it dangerous?

It disables escaping entirely; it removes the exact XSS protection HTL was built to provide, and should never be used just to "make a value work."

9. What's the functional difference between data-sly-resource and data-sly-include?

data-sly-resource renders a child resource through the full Sling resolution pipeline (selectors, resourceType inheritance); data-sly-include just pulls in another script's raw markup within the same component, with no resource-resolution pass.

10. Does an HTL comment () reach the visitor's browser?

No — it's stripped server-side and never leaves AEM, unlike a normal HTML comment.

10Servlets & Backend APIs

1. What's the AEM-native alternative to registering a servlet by URL path?

Registering it against a resource type (sling.servlet.resourceTypes), the same mechanism used for render script resolution.

2. What properties does the resourceType-based example combine to scope exactly which requests the servlet answers?

sling.servlet.resourceTypes, sling.servlet.selectors, sling.servlet.extensions, and sling.servlet.methods.

3. When is it better to use a Sling Model's @Exporter instead of writing a servlet at all?

When all you need is a resource's properties as JSON — @Exporter is simpler to maintain for that case.

4. Name three reasons you'd write an actual servlet instead of relying on @Exporter.

A non-GET verb, a request body, a response shape that isn't "this resource as JSON," or a side effect like writing content or calling another system.

5. Why prefer getRequestParameter over getParameter for reading input?

It's encoding-aware and avoids platform-default charset bugs getParameter is prone to on some setups.

6. What library does the SearchServlet example use to build a JSON response, and does it need an extra Maven dependency?

javax.json; no extra dependency needed since it ships with AEM.

7. Why is building JSON via string concatenation risky once a response has nested or repeated data?

A stray unescaped character breaks the response into invalid JSON — string concatenation doesn't handle escaping for you.

8. What has to happen before a client's POST/PUT/DELETE request will be accepted by Sling's CSRF filter?

The client must first fetch a token from /libs/granite/csrf/token.json and send it back as a CSRF-Token header.

9. A POST returns 403. What should you check before auditing ACLs/permissions?

The response body for a CSRF-related message — a 403 on a non-GET request is, more often than not, a missing CSRF token rather than a permissions problem.

10. When should you reach for a resourceType-based servlet over a path-based one?

When the endpoint is naturally "an action on this kind of resource" rather than a standalone utility.

11Dialogs & Components

1. What four things typically live inside a component's folder?

13Java Pitfalls in AEM

1. What's the classic symptom when a class overrides equals() but not hashCode(), and is used as a HashSet element?

contains() returns false for an object that should be "equal" — the two instances land in different hash buckets, so equals() never even gets called to compare them.

2. What's the rule about hashCode() and a HashSet/HashMap key whose fields can change after insertion?

Never use a mutable field in hashCode() for an object you intend to store as a key — if it changes after insertion, the object becomes unreachable via contains()/remove().

3. What's the difference in purpose between Comparable and a Comparator?

Comparable defines a class's single natural ordering (used by sort()/TreeSet/TreeMap); a Comparator defines an alternative ordering without changing the class itself.

4. What happens in a TreeSet if compareTo() returns 0 for two objects that equals() says are NOT equal?

The TreeSet silently drops one of them — it uses compareTo(), not equals(), to decide what counts as a duplicate.

5. What's the rule of thumb for choosing an interface versus an abstract class?

Interface = "any of these unrelated classes can do this" (a contract, no shared state); abstract class = "these classes are fundamentally the same kind of thing," sharing state/behavior. A class can implement many interfaces but extend only one class.

6. Why does this module recommend defaulting to interfaces for Sling Models and OSGi services specifically?

Composition via @Via only works against an interface boundary, and interfaces are what makes services swappable and mockable.

7. Why does calling a stream's terminal operation twice throw an exception?

A stream can only be consumed once; reusing it throws IllegalStateException: stream has already been operated upon or closed.

8. Where does a null inside a stream pipeline typically throw a NullPointerException, and why can that be confusing?

At the point it's dereferenced inside the pipeline (e.g. inside map()), not at the point it entered the stream — which can make the stack trace point somewhere unhelpful.

9. What's the recommended fix for debugging a long inline lambda/stream chain?

Break it into named, separately-callable methods before debugging — stepping through an inline lambda chain is much harder to follow than stepping through a named method.

10. Before reaching for a full IDE remote-debug session, what should you try first, and where?

Set a package's log level to DEBUG live via the Felix console's Sling Log Support (/system/console/slinglog) — no restart or redeploy needed.

14Unit Testing

1. Why does the module recommend extracting validation logic out of ValidationServlet into a standalone UsernameValidator class first?

Extracting logic out of a servlet into a plain class is, on its own, the single biggest thing you can do to make code testable.

2. What does @ParameterizedTest with @CsvSource let you do that a single @Test can't, conveniently?

Run the same test body once per row of input/expected-output data, covering multiple cases without writing near-identical test methods.

3. What's the key difference between a plain Mockito test and one using AemContext?

Plain Mockito mocks a dependency interface and is fast with no setup; AemContext is needed once code touches Resource, ResourceResolver, or relies on real OSGi service injection.

4. What does context.addModelsForClasses(...) do, and what happens if you forget it?

It registers a Sling Model class with the mock context so adaptTo() can find it; forgetting it means adaptTo() silently returns null.

5. In the ChildPagesModelTest example, what's actually being tested, and what AEM Mocks feature builds the test content?

ChildPagesModel's getChildPageTitles() sorting behavior; context.create().resource(...) builds the in-memory content tree.

6. What does context.registerInjectActivateService(servlet) do for a servlet under test?

Performs real field injection on the servlet's @Reference fields using services registered in the mock OSGi registry, exactly as the real OSGi runtime would.

7. Why does the GreetingServletTest example matter for the earlier "always use an interface" advice?

Without the GreetingService interface, there'd be nothing to register a fake implementation against — none of this would be mockable at all.

8. What's the stated best practice about what NOT to test?

Don't test the framework itself — there's no value in a test that only confirms ValueMap.get() works; test your own logic.

9. When should you prefer a plain Mockito test over setting up an AemContext?

Whenever your code doesn't actually touch Resource or OSGi — AemContext should only be used when genuinely needed.

10. What's the practical reason this module gives for preferring fast unit tests over redeploying to localhost:4502 for everyday feedback?

A unit test runs in milliseconds with no AEM instance required, while build/deploy/curl is slow and tests far more than just the one piece of logic you changed.

15Context-Aware Configuration

1. What problem does Context-Aware Configuration solve that run-mode configuration can't?

A value that differs per-site on the same instance, resolved by content hierarchy — run mode only describes the environment (author/publish), not which content is being requested.

2. What property links a page to its configuration tree under /conf?

sling:configRef.

3. What annotation defines a configuration type for CA Config, and does it need a separate @Component/@Designate registration?

@Configuration (with @Property on each field); no, CA Config's framework discovers @Configuration-annotated interfaces automatically.

4. How do you read a CA Config value from inside a Sling Model?

Adapt a resource or request (via @Self) to ConfigurationBuilder, then call .as(YourConfig.class).

5. If no sling:configRef is set on a page or its ancestors, what happens when you call ConfigurationBuilder.as()?

It silently falls back to the annotation's default values — which can look identical to "it's working" until you actually need a non-default value.

6. What does CA Config resolution actually do when walking from a resource up to find a value?

It walks up the content hierarchy through parent resources, following sling:configRef to locate the relevant /conf tree, falling back to a global default if nothing site-specific exists.

7. What problem does the WCM IO Context-Aware Configuration Editor solve that's missing out of the box?

Out of the box, CA Config values can only be edited as raw repository content under /conf; the editor adds a proper UI so non-developers can edit them without CRXDE Lite.

8. Where do the editor's form fields and labels come from?

They're generated directly from your @Configuration/@Property annotation interface — no separate UI code needed.

9. What AemContext feature is needed to unit test code that depends on a CA Config value?

The CACONFIG context plugin (new AemContext(ContextPlugins.CACONFIG)), letting you write config values directly into the mock /conf tree.

10. What's the suggested fix for WeatherModel's blank-country fallback, tying CA Config back to the components workshop?

Use ConfigurationBuilder to fall back to config.defaultCountry() whenever the dialog's country field is left empty.

16Workflows & Event Handling

1. What's the decision rule for choosing between a workflow, an event listener, and a scheduled job?

Does a person need to see and act on it → workflow. Should it happen automatically on a change → listener. Does it need to run on a clock → scheduler.

2. What interface does a custom workflow step implement, and what makes it show up in the workflow model editor's UI?

WorkflowProcess; the process.label OSGi component property is what authors see when building a workflow model.

3. What's the modern replacement for the older JCR ObservationListener API, and what's different about it?

ResourceChangeListener — a simpler interface scoped to specific paths and change types.

4. What two OSGi component properties scope a listener to additions and changes under a specific content path?

ResourceChangeListener.PATHS (the path) and one or more ResourceChangeListener.CHANGES entries (e.g. "ADDED", "CHANGED").

5. What's the common pitfall called out about code running inside onChange()?

It runs synchronously on the thread that triggered the change — a slow listener can visibly delay authoring or replication.

6. What's the recommended fix for heavier work that a listener triggers?

Hand it off to a Sling Job (JobManager.addJob(...)) instead of doing the real work inline.

7. What does the Sling Scheduler's cron-like expression "0 0 2 * * ?" mean in the example?

Run at 2am daily.

8. What does canRunConcurrently(false) protect against on a scheduled task?

A second run starting before the previous one has finished.

9. Give a real example of each of the three automation tools, as used in this module.

Workflow → "Request for Activation"; listener → auto-tagging a page the moment it's created; scheduled job → a nightly report.

10. What's the WorkItem's payload typically used for, in a custom workflow step?

It carries the path of the content the workflow is acting on (workItem.getWorkflowData().getPayload()).

17Workflow Design & Custom Steps

1. Use the "recipe vs. dish" analogy from this module: what's a workflow model, and what's a workflow instance?

The model is the recipe (the reusable design/sequence of steps); the instance is one specific run of that model against one payload, with its own independent state.

2. A workflow seems "stuck" for one specific page but works fine for everything else. Where should you look first?

That page's specific workflow instance state, not the model design — the model is shared and almost certainly fine.

3. Name the three standard ways a workflow instance gets created.

Manually (an author selects "Start Workflow"), automatically via a launcher, or programmatically via the Workflow Java API.

4. What's a launcher, in workflow terms, and what's its closest equivalent from an earlier module?

A visually-configured trigger that starts a model whenever content matching a path/event type changes — the workflow equivalent of ResourceChangeListener, but configured rather than coded.

5. What are "stages" in the Workflow Model Editor for?

Breaking a complex process into readable phases (like "Draft Review," "Legal Approval," "Publish") instead of one long flat chain of steps.

6. What's the difference between a Participant Step and a Dynamic Participant Step?

A Participant Step assigns a task to a fixed person/group; a Dynamic Participant Step resolves the assignee by script.

7. Which step type maps to the WorkflowProcess Java code you write?

A Process Step.

8. In the AcademyApprovalStep example, how does a step read metadata configured on it inside the visual editor, and how does it hand data to a later step?

args.get(...) (a MetaDataMap) reads step-level config; writing into workItem.getWorkflow().getWorkflowData().getMetaDataMap() hands data forward.

9. Why should a custom workflow step be idempotent?

AEM can retry a failed step, so running execute() twice for the same work item should never cause duplicate side effects (like sending two emails).

10. What's the best-practice guidance on where a step's actual logic should live?

In a separate, unit-testable service rather than written inline in execute() — the same "thin model, logic in a service" advice from earlier modules.

18Sling Jobs

1. What separates a Sling Job from the plain Sling Scheduler, in terms of durability?

A Sling Job is persistent — if the instance restarts mid-job, the job isn't lost and is retried per the queue's configuration, unlike the plain scheduler.

2. What does a job's topic identify?

Which registered consumer/executor handles that unit of work.

3. What's required before getServiceResourceResolver(...) will work inside a job executor, and what's the symptom of forgetting it?

A service user mapping configured for the named subservice (e.g. "academy-weather-writer"); forgetting it causes a login exception that looks unrelated to the actual business logic.

4. What's the difference between triggering an immediate job and registering a scheduled job?

An immediate job (jobManager.addJob(...)) runs right away in response to something happening; a scheduled job (jobManager.createJob(...).schedule()...add()) is registered once, typically in @Activate, and runs repeatedly on its own.

5. What does the cron expression "0 */15 * * * ?" mean in the recurring job example?

Every 15 minutes.

6. What's the practical payoff of moving WeatherModel's weather fetch into a scheduled job?

WeatherModel can read from a cached value instead of making a live HTTP call on every page render — pages load instantly regardless of Open-Meteo's responsiveness.

7. What does queue.type: UNORDERED mean for how jobs on that queue are processed, versus ORDERED?

UNORDERED processes jobs in parallel with no guaranteed order; ORDERED processes jobs on the same topic strictly one at a time.

8. Which queue.type would you choose if later jobs depend on earlier ones having finished?

ORDERED.

9. What do queue.retries and queue.retrydelay control?

What happens when process() returns a failed result — how many times and how long to wait before retrying.

10. Where does queue configuration live, and what naming pattern does its factory config file follow?

A .cfg.json under ui.config, named after org.apache.sling.event.jobs.QueueConfiguration with a ~name suffix for the factory config instance.

19Dispatcher, Caching & Deployment

1. What four sections make up a typical dispatcher farm configuration?

/cache/rules, /cache/invalidate, /filter, and /statfileslevel (plus /clientheaders) — broadly: cache, rules, filter, invalidate.

2. What's the job of /cache/rules versus /cache/invalidate?

/cache/rules decides what's allowed to be cached at all; /cache/invalidate decides what gets thrown out when content changes.

3. In the example rule set, why is anything with a query string explicitly denied from caching?

Query strings usually mean personalized or parameterized output that shouldn't be cached for everyone.

4. What does statfileslevel control, and when is it the first thing worth checking?

How deep the dispatcher checks a folder's .stat file timestamp to decide whether cached content under that path still needs revalidating — check it first when invalidation seems to be "not reaching" a nested path.

5. Walk through what happens, step by step, when an author activates a page.

A flush agent on publish sends an invalidation request to the dispatcher, which deletes the matching cached files so the next visitor regenerates fresh output.

6. Why does /cache/invalidate commonly remove *.html but leave heavier assets like images untouched?

To avoid an expensive mass re-fetch over something that didn't actually change — images are far more expensive to regenerate than HTML.

7. Is /filter a caching mechanism or a security mechanism?

Security — it's a deny-by-default allow-list deciding what's even allowed to reach AEM, unrelated to caching decisions.

8. What's the standard pattern for writing /filter rules?

Deny everything first, then explicitly allow only the specific extensions, selectors, and paths your application actually serves.

9. Which earlier module first introduced the dispatcher conceptually, before this module's actual configuration?

Module 1, Architecture Overview.

10. Why would a request return correctly when tested directly against publish, but get rejected when going through the dispatcher?

The dispatcher's /filter allow-list rejected it before it ever reached AEM — a security concern separate from whether AEM itself would have served it.

1. What problem is the Groovy Console specifically meant to solve, compared to writing a full OSGi bundle?

The same JVM bytecode as Java; it can call any Java API directly, so everything you know about ResourceResolver/Resource/JCR still applies.

Through AEM's Package Manager (/crx/packmgr) → Upload Package → select the file → Install.

6. Why should the Groovy Console never be installed on a production publish instance?

It grants whoever has access the ability to run arbitrary code with full repository permissions.

7. What useful object does the console pre-bind for you, so you don't need to obtain it yourself?

A ResourceResolver.

8. In the example backfill script, what does setting dryRun = true actually do?

It prints what would change ("Would update: ...") without calling resourceResolver.commit(), so nothing is actually modified.

9. What API does the script use to actually write the new property once dryRun is false?

Adapting the resource to ModifiableValueMap and calling .put(...), followed by resourceResolver.commit().

Running the script once with dryRun = true and reading the output carefully before flipping it to false.

22Dynamic Forms / Adaptive Forms

1. What does 'adaptive' mean in the context of Adaptive Forms — give two specific examples of what a form adapts to.

A form adapts to the device (responsive layout for mobile vs desktop) and to user input (showing/hiding fields based on what the user selects, e.g. showing a "Spouse income" field only when "Married" is chosen).

2. What are the two generations of AEM Forms components, and which should you use for new projects?

Foundation Components (legacy, JSP-based, no new features) and Core Components (modern, HTL + Sling Models, actively developed). Always use Core Components for new projects.

3. Name the Form Container's three key configuration responsibilities.

Submit action (what happens on submit), data binding / data model (JSON schema or FDM), and prefill service (which service pre-populates fields on load).

4. What is the Form Data Model (FDM) and what problem does it solve?

The FDM is an abstraction layer over external data sources (REST APIs, databases, OData). It lets forms read and write backend data without hard-coding connection details in the form itself.

5. Name three types of data sources you can connect to a Form Data Model.

RESTful web services (Swagger/OpenAPI), SOAP web services (WSDL), OData services (e.g. Microsoft Dynamics), relational databases (JDBC), AEM User Profile. Any three count.

6. An author wants 'Spouse income' to appear only when 'Married' is selected. Which tool do they use, and does it require a developer?

The Rule Editor — the no-code visual tool built into the AEM Forms page editor. No developer needed for standard show/hide rules.

7. Name four built-in submit actions in AEM Adaptive Forms.

Submit to REST endpoint, Invoke a Form Data Model Service, Send Email, Store in AEM Repository (CRX), and Custom submit action. Any four count.

8. A form rule references a field named 'dob'. A developer renames the field to 'dateOfBirth'. What breaks?

Every Rule that references the field name 'dob' silently breaks — the rule no longer finds the field and does nothing. Rules target components by their Name property.

9. What is the difference between a panel and a wizard layout in Adaptive Forms?

A panel groups fields in a single visible section. A wizard renders multiple panels as sequential numbered steps with Next/Previous navigation and per-step validation.

10. Where in the AEM author environment do you navigate to create or manage Adaptive Forms?

localhost:4502/aem/forms — the AEM Forms portal, separate from the Sites console.

23Form Fragments & Sample Code

1. What is the key difference between including a fragment and copy-pasting components into a form?

A fragment is a reference — updating the fragment propagates to all consuming forms automatically. Copy-paste creates an independent copy; each instance must be updated individually.

2. Where are form fragments stored in the AEM repository?

Under /content/dam/formsanddocuments/ — the DAM, the same storage layer used for images and other digital assets.

3. You update a fragment by adding a new field. What else must you do for consuming forms to show the change in production?

Publish (or republish) the fragment. An unpublished fragment update is invisible on the publish instance — the old version is still cached there.

4. What does the fragmentPath property on a Fragment component contain?

The JCR path to the fragment in the DAM (e.g. /content/dam/formsanddocuments/academy-fragments/address-block). It's a path reference, not a copy of the content.

5. What is a JSON schema in the context of Adaptive Forms, and where is it stored?

A JSON schema defines the shape and types of the form's submitted data — a typed contract. It's stored in the DAM (e.g. /content/dam/formsanddocuments/schemas/) and referenced from the Form Container's Data Model tab.

6. A textinput has dataRef = 'applicant.firstName'. What does the submitted JSON look like?

{ "applicant": { "firstName": "value entered by the user" } } — the dot-notation maps to nested JSON object paths.

7. What is a prefill service, and when would you use one?

A prefill service reads data from a backend source and pre-populates form fields when the form first loads. Use it when AEM already knows some of the user's data (e.g. logged-in user's address from a CRM) and you want to save the user from re-entering it.

8. Which OSGi interface must a prefill service implement?

com.adobe.forms.common.service.DataXMLProvider — registered with @Component(service = DataXMLProvider.class).

9. A developer 'detaches' a fragment from a form. What happens to future updates to the original fragment?

Detaching converts the reference to a local copy. The form no longer inherits from the fragment — future fragment updates no longer affect this form.

10. The Form Container has prefillService = 'biz.netcentric.academy.forms.LoanPrefillService'. What does AEM do with this when the form loads?

AEM looks up the OSGi service registry for a DataXMLProvider whose getServiceName() returns 'LoanPrefillService', calls its getDataXMLForDataRef() method, and uses the returned XML/JSON to pre-populate form fields before rendering.

24Implementing Adaptive Forms

1. Why must the AEM Forms SDK API dependency use <scope>provided</scope> in pom.xml?

AEM already ships the Forms API classes at runtime via the Forms add-on. Bundling them into your JAR would cause class conflicts. Provided scope compiles against them but excludes them from the output bundle.

2. What is the difference between the 'embeddedform' and iframe approaches?

embeddedform renders the form inline in the page DOM — sharing CSS, scripts, and navigation. The iframe isolates the form in its own browsing context, separated from parent page styles. Use iframe when the consumer is not AEM (React SPA, external portal).

3. Which Java interface must a custom submit action implement?

com.adobe.aemds.guide.service.GuideSubmitAction

4. How does AEM Forms discover custom submit actions registered in the OSGi bundle?

The @Component annotation registers the class as service = GuideSubmitAction.class in the OSGi registry. AEM Forms' engine queries all active GuideSubmitAction services at startup and lists them in the Form Container dialog by their getServiceDescription() string.

5. What does GuideSubmitInfo give you access to inside a submit action?

The submitted data as a JSON string, the form definition, attached files, and the adaptive form object (for reading form-level properties like thankYouPage).

6. What file format must a REST API provide before you can connect it as an FDM data source?

A Swagger 2.0 or OpenAPI 3.0 specification file (YAML or JSON), uploaded to the AEM DAM.

7. Walk through the five steps to connect a REST API to a Form Data Model.

1) Upload the Swagger spec to the DAM. 2) Create a Data Source in Tools → Cloud Services → Data Sources. 3) Create a Form Data Model in AEM Forms → Data Integrations, selecting the data source and exposing operations. 4) Bind the FDM to your form via the Form Container's Data Model tab. 5) Bind individual fields to FDM properties via each field's dialog.

8. What clientlib category must a custom JavaScript validator use?

fd.af.validator — AEM Forms scans clientlibs with this category and makes their functions available in the Rule Editor's Custom Functions palette.

9. What should a custom JavaScript validator return on success? On failure?

Return true on success. Return a string (the error message to display) on failure. AEM Forms displays the returned string as the field's inline validation error.

10. You deploy a custom submit action but it doesn't appear in the Form Container dialog. What is the first thing you check?

/system/console/components — verify the component is ACTIVE. If it's not active, check which @Reference field has no active provider, or check the bundle is ACTIVE in /system/console/bundles.

25Adobe Tags — Setup & Concepts

1. What was Adobe Tags called before it was renamed, and what is its full current official name?

It was called Adobe DTM, then Adobe Launch. The current name is Adobe Experience Platform Tags (often shortened to AEP Tags or just "Tags").

2. In one sentence, explain the core value of a tag management system for a marketing team.

One embed code is added to the site once by a developer; everything else (tracking scripts, analytics config, A/B test events) is then managed by the marketing team in a UI without code deployments.

3. What is a Tag Property, and how many should you create for a single website?

A Property is a container for all Tag configuration belonging to one site (Extensions, Data Elements, Rules, Environments). One property per website is the standard approach.

4. What is an Extension in Adobe Tags — give two examples.

An Extension is a plugin that adds capabilities to a Property. Examples: Adobe Analytics extension (adds Analytics tracking actions), Core extension (adds built-in events like Page Loaded and DOM Ready).

5. What is a Data Element? Draw an analogy to AEM development.

A Data Element is a named variable that references a specific piece of page data (e.g. "Page Name" reads document.title). AEM analogy: like @ValueMapValue in a Sling Model — reads data by property name and exposes it under a clean name for reuse.

6. Name the three parts of a Rule in Adobe Tags.

Event (when it fires, e.g. Page Loaded), Condition (optional filter, e.g. URL contains "/checkout"), Action (what to do, e.g. Set Analytics variables + Send Beacon).

7. What are the three publishing Environments, and why do they matter?

Development (instant updates, unminified — for development iteration), Staging (approval workflow — for QA), Production (approval workflow — for the live site). Each has its own embed URL so AEM can load the right one per run mode.

8. How does AEM Sites include the Tags embed code on every page without template changes?

Via an AEM Cloud Services configuration under /conf/ — the same Context-Aware Config mechanism from module 15. AEM Core Components' Page component reads it and injects the correct <script> tag in <head> automatically.

9. In a Set Variables action, eVar1 = %Page Name%. What does %Page Name% mean?

%Page Name% is a Data Element reference. At runtime Tags resolves the "Page Name" Data Element (e.g. reads document.title) and substitutes its value into eVar1.

10. What is the difference between s.t() and s.tl() in Adobe Analytics?

s.t() is a page view call — increments the Page Views metric. s.tl() is a link tracking call for clicks, downloads, and custom events that should NOT be counted as page views.

26Implementing Adobe Tags in AEM

1. What is the ACDL, and how does it get populated on an AEM Core Components page?

The Adobe Client Data Layer (window.adobeDataLayer) is a JavaScript object providing structured page data. Core Components push their data (page info, component details, user state) to it as inline script blocks during server-side rendering.

2. What OSGi config enables the ACDL, and what is the key property?

com.adobe.cq.wcm.core.components.internal.services.DataLayerConfig.cfg.json with "enabled": true. Place it in ui.config under the appropriate run-mode config folder.

3. What Tags Data Element type reads from the ACDL, and what does the 'path' field contain?

The "Data Layer Computed State" type from the Adobe Client Data Layer extension. The path is a dot-notation string matching the ACDL JSON structure, e.g. page.pageInfo.pageName.

4. Write the Tags Data Element configuration to read page.pageInfo.pageName from the ACDL.

Name: "Page Name". Extension: Adobe Client Data Layer. Type: Data Layer Computed State. Path: page.pageInfo.pageName. Default Value: "(unknown)".

5. A developer wants Tags to fire when a download button is clicked. What must they add to the component's clientlib JavaScript?

An event listener on the button that calls window.adobeDataLayer.push({ event: 'academy:download', eventInfo: { value: { documentTitle: ..., documentPath: ... } } }) when clicked.

6. In an ACDL push, what is the 'event' property used for in Tags?

The event name that Tags Rules listen for. A Rule with event type "ACDL Event Listener" fires when a push with that specific event name occurs.

7. Name the two AEP Debugger tabs most useful for verifying a Tags/Analytics implementation.

The Launch tab (shows which library loaded and which Rules fired) and the Analytics tab (shows decoded eVar/prop/event values and whether a beacon was sent).

8. What does filtering the Network tab by 'b/ss/' show you?

Adobe Analytics server calls (beacons) sent to the tracking server. The URL query parameters contain all eVars, props, and events as raw key=value pairs — the ground truth for what Analytics received.

9. What is the key architectural difference between the Analytics Extension and the Web SDK?

The Analytics Extension uses AppMeasurement.js and sends data only to Adobe Analytics. The Web SDK (Alloy.js) sends a single XDM-formatted beacon to an AEP Datastream, which routes data to multiple products (Analytics, Target, CJA, RTCDP) simultaneously.

10. When would you choose the Web SDK over the Analytics Extension for a new project?

When building on the full Adobe Experience Platform — especially if you need Adobe Target, Customer Journey Analytics, Real-Time CDP, or Offer Decisioning alongside Analytics. For Analytics-only projects with existing admin expertise in eVars/props, the Analytics Extension is still the right choice.

27Adobe Analytics Workspaces

1. What is a Report Suite, and why should dev and production use separate suites?

A Report Suite is the data silo where all tracking data for a site lands — like a database per brand. Dev and production must use separate suites because development testing data (page reloads during coding, dummy submissions) would pollute production reports and skew all metrics.

2. Explain the difference between a Dimension and a Metric. Give one example of each.

A Dimension is a categorical variable — what you're looking at. Example: Page Name (values: "Home", "Checkout", "About Us"). A Metric is a quantitative measurement — how many. Example: Page Views (values: 1,200 / 450 / 89).

3. What is a Segment in Workspace, and how is it different from filtering a single table column?

A Segment is a reusable filter applied to an entire Panel (or project), restricting all visualisations to a subset of visitors/visits. A column filter only affects that column in one Freeform Table. Segments are saved and reusable across projects.

4. What is the difference between a Visit, a Visitor, and a Page View?

Page View = one page load. Visit = a session (series of page views within 30 minutes of inactivity). Visitor = a unique person (cookie-based). One Visitor can have many Visits; one Visit can contain many Page Views.

5. You want to see which pages lost the most traffic vs last month. Which visualisation and configuration?

A Freeform Table with the Page dimension in rows and Page Views metric in columns. Add a date comparison: set the panel date range to "This Month" and enable "Compare to previous period" to add a delta column showing the change.

6. What does a Fallout visualisation measure, and what is the common misconception?

Fallout measures sessions that touched each defined step in order — answering "what % of sessions went through steps A → B → C?" The common misconception is that steps must be consecutive; in reality, a user can visit many other pages between steps and still be counted as having completed the funnel.

7. An analyst reports email drives 2% of conversions; another says 35%. Both are right. How?

They're using different attribution models. Last Touch gives 100% credit to the final channel before conversion — direct visits often win, pushing email to near-zero. Linear or Time Decay attribution spreads credit across all touchpoints, so email's assist role is recognised and its share rises dramatically.

8. What is the difference between AND and THEN in a sequential segment?

AND means both conditions must be present in any order within the container's scope. THEN means Condition 1 must occur before Condition 2 — it enforces chronological sequence. Use THEN for funnel analysis (viewed product page THEN reached checkout).

9. An executive with no Analytics licence needs a weekly summary. What sharing approach?

Share → Schedule File. Set format to PDF, frequency to Weekly, and add the executive's email. They receive a snapshot every week with no login required — scheduled PDFs don't need an Analytics licence to receive.

10. What is a Virtual Report Suite, and when would you create one?

A VRS is a filtered, curated view of a main Report Suite given to a team or business unit. They see only the data relevant to their product area, with only the dimensions and metrics relevant to them exposed. Create one when multiple teams share one Report Suite but need self-service access without seeing each other's data or getting lost in hundreds of unrelated components.
